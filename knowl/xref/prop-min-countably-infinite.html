Proposition A.1.3.

A set \(A\) is infinite if and only if \(|\N|\le |A|\text{.}\)
🔗
🔗

Proof.
If \(f:\N\to A\) is injective, then \(f(\N)\) is an infinite subset of \(A\text{,}\) so \(A\) is infinite. Conversely, suppose that \(A\) is infinite. Choose \(a_1\in A\text{,}\) and recursively choose \(a_{n+1}\in A\setminus\{a_1,\ldots,a_n\}\text{.}\) This is possible at every stage because \(A\) is not finite. The map \(n\mapsto a_n\) is an injection from \(\N\) to \(A\text{.}\)
