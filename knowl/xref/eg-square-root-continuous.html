Example 4.1.7.

The function \(f(x)=\sqrt{x}\) is continuous on its domain \([0,\infty)\text{.}\) For \(x,c \ge 0\text{,}\)
\begin{equation*} |x-c|=|\sqrt{x}-\sqrt{c}|(\sqrt{x}+\sqrt{c}) \ge |\sqrt{x}-\sqrt{c}|^2. \end{equation*}
Given \(\varepsilon \gt 0\text{,}\) choose \(\delta=\varepsilon^2\text{.}\) Then for any \(x \ge 0\) with \(|x-c| \lt \delta\text{,}\)
\begin{equation*} |\sqrt{x}-\sqrt{c}|^2 \le |x-c| \lt \varepsilon^2, \end{equation*}
so \(|\sqrt{x}-\sqrt{c}| \lt \varepsilon\text{.}\) This holds for every \(c \in [0,\infty)\text{,}\) including the endpoint \(0\text{.}\)
